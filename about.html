关于格物

ABOUT GEWU

格物致知，出自《礼记·大学》：「致知在格物，物格而后知至。」——研究事物，方能获得知识。这就是本站的全部主张。

v1.0 纯前端 · 静态站点 可离线运行

为什么是「科研 · 可视化 · 知识传播」？

通用工具箱解决的是「文件怎么办」——压缩、转换、格式互转。而科研工作者的日常是另一条流水线： 读文献、记笔记、做分析、画图、写作、传播。这条流水线上的工具往往分散在 Overleaf、Zotero、Matplotlib、公众号编辑器等十几个站点之间，各有账号、各有上传。

格物把这条流水线收进一个浏览器标签页：公式与文献是「研」，函数、图表、分布与图谱是「视」， 卡片、排版、代码图、幻灯片与导图是「传」。它们不是孤立的小工具，而是一套工作流的零件。

与通用工具箱的差异

维度 通用工具箱（如 MeTool 类） 格物 GEWU
规模 80+ 工具，覆盖图片、视频、游戏、魔法 15 件，只服务科研工作流
组织方式 按文件类型分类 按工作流工序编排（读→记→析→绘→写→传）
社交功能 登录、反馈中心、留言 刻意不做：无账号、无留言、无反馈表单
数据 多数本地处理，部分链接第三方存储 100% 本地：localStorage 存档、Blob 导出
统计 含分析脚本与广告 零分析、零广告、零追踪脚本

技术栈：刻意朴素

原生 HTML / CSS / JavaScript，无框架、无构建步骤、无后端。依赖库（marked、KaTeX、highlight.js） 全部下载到 js/lib/ 本地引用，连上服务器之后也可以离线打开。页面结构上， 页头页脚由 js/site.js 注入，工具目录由 js/catalog.js 单一数据源驱动—— 加一件工具只改一处。

所有数学计算（分布函数、力导向、BibTeX 解析、随机化）都在本机完成；所有导出（SVG / PNG / HTML / CSV）都通过浏览器 Blob 下载。关掉页面，一切即销毁——除了你自己决定保存的文件。

我们刻意不做的事
  • 不做留言工具——知识传播是单行道，评论交给读者自己消化
  • 不做账号系统——没有「我的」，只有「工具」
  • 不碰你的文件——没有服务器，就没有上传
  • 不放大而全——15 件工具，件件有工序位置
  • 不投放广告——本站没有分析脚本与跟踪像素
  • 不做加密登录页——打开即用
使用方式
  • 直接双击 index.html 即可打开（部分页面需要浏览器较新版本支持）
  • 或本地起服务：python3 -m http.server 8080
  • 笔记台草稿、主题偏好存于浏览器 localStorage
